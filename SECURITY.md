# Security Policy

## Supported versions

Only the most recent tagged release is supported with security fixes. Older versions may receive critical fixes at the maintainers' discretion.

## Reporting a vulnerability

Please report security issues **privately**. Do not open public GitHub issues for vulnerabilities.

- Email: `security@energychainnetwork.io`
- or open a private vulnerability advisory under the repository's *Security* tab.

When reporting, please include:

- A description of the issue and the version / commit SHA affected.
- Steps to reproduce or a proof-of-concept.
- Your assessment of the impact (data loss, fund loss, downtime, etc.).
- Whether you intend to publish the issue, and on what timeline.

We aim to acknowledge within 48 hours and will coordinate a fix and disclosure timeline with the reporter. Researchers acting in good faith will be credited in the release notes (unless they prefer to remain anonymous).

## Out-of-scope

- Issues in third-party dependencies — please report upstream first.
- Self-inflicted damage from running with `--unsafe-*` / debug flags.
- Theoretical issues without a working PoC against a maintained release.
